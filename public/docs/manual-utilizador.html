0. Turnos — Abrir e Fechar

O sistema trabalha com dois turnos por dia: Manhã (07h00 — 14h00) e Tarde (14h00 — 22h00). Cada operador deve abrir o seu turno no início e fechá-lo no final. O fecho do dia só pode ser feito quando ambos os turnos estiverem fechados.

0.1 Como Abrir um Turno

Passo 1: No Terminal POS, clique no botão "TURNO" (canto inferior esquerdo).

Passo 2: Escolha o turno:

  • MANHÃ — 07h00 às 14h00 (almoço)
  • TARDE — 14h00 às 22h00 (jantar)

Passo 3: Insira o valor em caixa (dinheiro físico que tem para troco). Ex: 10.000 Kz.

Passo 4: Clique em "ABRIR TURNO".

Exemplo: A operadora de caixa Ana chega às 07h00. Clica em TURNO, escolhe MANHÃ, insere 15.000 Kz (troco para o dia), e confirma. O turno fica "ABERTO".
DICA: Anote o valor que inseriu. No final do turno, o sistema pergunta quanto dinheiro tem — deve corresponder ao valor de abertura + vendas em numerário.

0.2 Durante o Turno

Todas as vendas que faz durante o turno ficam associadas automaticamente ao turno aberto. Não precisa fazer nada especial — é só usar o POS normalmente.

O que fica ligado ao turno:

  • Todas as mesas abertas e fechadas
  • Todos os pagamentos (numerário, multicaixa, TPA, transferência)
  • Todos os produtos vendidos
  • Quantidade de vendas realizadas

0.3 Como Fechar um Turno

Passo 1: Clique no botão "TURNO" no POS.

Passo 2: O sistema mostra o resumo do turno:

  • Vendas por modalidade: Numerário, Multicaixa, TPA, Transferência, QR Code
  • Produtos vendidos: Lista de cada produto com quantidade e total
  • Total de vendas: Soma de todas as vendas do turno
  • Número de vendas: Quantas contas foram fechadas

Passo 3: Clique em "VER RELATÓRIO" para ver o preview completo.

Passo 4: Conte o dinheiro físico em caixa (só numerário).

Passo 5: Insira o valor contado no campo "Valor em caixa".

Passo 6: O sistema calcula a diferença:

  • Esperado: Valor de abertura + vendas em numerário
  • Contado: O que contou fisicamente
  • Diferença: Se for 0 Kz = OK. Se for positivo = sobra. Se for negativo = falta.

Passo 7: Clique em "FECHAR TURNO" para confirmar.

Passo 8: O relatório pode ser impresso automaticamente.

ATENÇÃO: Se houver diferença (falta ou sobra), NÃO ignore. Anote o valor e explique no campo de observações. O gerente precisa saber.

1. Terminal POS — Vendas

O Terminal POS é onde se registam todos os pedidos dos clientes. É o menu mais usado no dia-a-dia.

1.1 Como Abrir uma Mesa

Passo 1: No ecrã principal do POS, clique no botão "NOVA MESA".

Passo 2: Aparece uma grelha com os números das mesas. Clique na mesa que quer abrir.

Passo 3: Escolha o tipo:

  • LOCAL — Cliente no restaurante (mesa normal)
  • ENTREGA — Delivery/takeaway (precisa nome e telefone)

Passo 4: Se ENTREGA, preencha nome e telefone do cliente.

Passo 5: Confirme. A mesa fica aberta e pronta para adicionar itens.

1.2 Como Adicionar Itens ao Pedido

Passo 1: Com a mesa aberta, veja as categorias na barra lateral (Entradas, Pratos, Bebidas, Sobremesas, etc.).

Passo 2: Clique numa categoria para ver os produtos disponíveis.

Passo 3: Clique no produto para adicioná-lo ao pedido. Cada clique adiciona 1 unidade.

Passo 4: Para ajustar quantidade: use os botões + e − ao lado do item no carrinho.

Passo 5: Para remover um item: clique no ícone de lixo ao lado do item.

Passo 6: Para adicionar observação (ex: "sem cebola"): clique no ícone de lápis ao lado do item.

1.3 Como Enviar Pedido para a Cozinha

Passo 1: Depois de adicionar todos os itens, clique no botão verde "ENVIAR PEDIDO".

Passo 2: Confirme o envio.

Passo 3: O pedido aparece no Monitor de Cozinha com o número da mesa, itens e observações.

Passo 4: Pode adicionar mais itens depois e enviar novamente — o cozinheiro vê a atualização.

1.4 Como Processar Pagamento

Passo 1: Clique em "FECHAR CONTA" no POS.

Passo 2: O ecrã mostra o resumo: itens, quantidades, preços, TOTAL GERAL.

Passo 3: Selecione o método de pagamento:

  • NUMERÁRIO — digite valor recebido, sistema calcula troco
  • MULTICAIXA — passe cartão no terminal POS
  • TPA — use referência de pagamento
  • TRANSFERÊNCIA — anote comprovativo
  • DÍVIDA — cliente fica a dever (só com autorização)

Passo 4: Verifique o valor.

Passo 5: Clique "CONFIRMAR PAGAMENTO".

Passo 6: Recibo imprime automaticamente (se houver impressora).

Passo 7: Mesa passa a "Fechada".

DÍVIDA: Deve ser liquidada antes do fecho do dia. Só use com autorização do gerente.

1.5 Sub-Contas (Dividir Conta)

Para dividir a conta de uma mesa entre vários clientes:

Passo 1: Abra a mesa que quer dividir.

Passo 2: Clique no botão "SUB-CONTA" ou "DIVIDIR".

Passo 3: Mova itens entre a conta principal e a sub-conta.

Passo 4: Cada sub-conta pode ser paga separadamente.

1.6 Monitor do Cliente (2º Ecrã)

Para mostrar o total ao cliente num segundo monitor:

Passo 1: Clique no ícone de Monitor no POS.

Passo 2: O sistema abre uma janela no segundo ecrã (se disponível).

Passo 3: O cliente vê os itens e o total em tempo real.

2. Mapa de Sala

O Mapa de Sala mostra a disposição visual de todas as mesas do restaurante.

2.1 Cores das Mesas

  • 🟢 VERDE — Mesa livre (clique para abrir POS)
  • 🟠 LARANJA — Mesa ocupada (clique para ver pedido)
  • 🔴 VERMELHO — Mesa com dívida pendente
  • 🔵 AZUL — Mesa com reserva marcada

2.2 Operações no Mapa

Abrir POS: Clique numa mesa verde para abrir o POS diretamente nessa mesa.

Ver pedido: Clique numa mesa laranja para ver os itens do pedido atual.

Mover mesa: Clique e arraste para reorganizar o layout.

Histórico: Clique direito numa mesa para ver histórico dos últimos 30 dias.

DICA: Reorganize as mesas para corresponder ao layout real do restaurante. O layout fica guardado automaticamente.

3. Reservas

O sistema de reservas permite marcar mesas para clientes em datas e horários específicos.

3.1 Criar Reserva

Passo 1: Aceda a "RESERVAS" na barra lateral.

Passo 2: Clique "NOVA RESERVA" (canto superior direito).

Passo 3: Preencha:

  • Nome do cliente (ex: "Família Santos — Aniversário")
  • Telefone com +244 (ex: +244 923 456 789)
  • Data — clique no calendário
  • Hora — formato 24h (ex: 19:30)
  • Número de pessoas
  • Mesa preferida (opcional)

Passo 4: Em OBSERVAÇÕES, adicione detalhes importantes:

  • "Aniversário — trazer bolo surpresa às 21h"
  • "Cliente VIP — mesa junto à janela"
  • "Criança com alergia a amêndoa"

Passo 5: Clique "GUARDAR RESERVA".

Passo 6: A mesa fica AZUL no Mapa de Sala.

ATENÇÃO: Só pode editar/cancelar até 2 horas antes do horário marcado. Reservas expiradas vão para o Histórico.

3.2 Gerir Reservas

Lista de reservas: Mostra todas as reservas ordenadas por data/hora.

Filtros: Hoje, Esta Semana, Próximas, Histórico.

Editar: Clique numa reserva para editar ou cancelar.

Confirmar chegada: Quando o cliente chegar, marque como "Confirmada" — a mesa fica pronta para abrir no POS.

4. Eventos

Eventos permitem gerir ocasiões especiais: casamentos, aniversários, jantares de grupo.

4.1 Criar Evento

Passo 1: Aceda a "EVENTOS" na barra lateral.

Passo 2: Clique "NOVO EVENTO".

Passo 3: Preencha:

  • Tipo: Casamento, Aniversário, Jantar de Grupo, ou Outro
  • Nome (ex: "Casamento Joana e Pedro")
  • Data e Hora (ex: 20/06/2026 às 18:00)
  • Convidados (ex: 50 pessoas)
  • Menu especial — descrição do menu acordado
  • Preço por pessoa (ex: 8.000 Kz)

Passo 4: O sistema calcula automaticamente:

  • Receita estimada = convidados × preço (ex: 50 × 8.000 = 400.000 Kz)
  • Custo estimado (baseado nos ingredientes)
  • Lucro estimado = receita − custo

Passo 5: Guarde o evento.

4.2 Gerir Eventos

Lista: Mostra eventos próximos, em curso e arquivados.

Editar: Pode editar até a data do evento. Depois é arquivado.

Observações: Use para detalhes como "Decoração rosa e branco", "DJ até meia-noite".

5. Fecho de Turno (Detalhado)

O fecho de turno fecha o período de trabalho e gera um relatório completo.

5.1 Relatório de Fecho de Turno

O relatório inclui:

  • Cabeçalho: Data, tipo de turno (Manhã/Tarde), nome do operador
  • Abertura: Valor inicial em caixa
  • Vendas por modalidade: Cada método com quantidade e valor
  • Produtos vendidos: Lista completa com quantidade e valor total
  • Resumo: Esperado, Contado, Diferença, indicador OK ou NÃO OK
  • Rodapé: Linha para assinatura do operador
DICA: Guarde o recibo do fecho de turno. É o comprovativo oficial das vendas do turno.

6. Fecho do Dia

O Fecho do Dia fecha o dia operacional completo (05:00 às 04:59) e gera o relatório oficial.

6.1 Pré-requisitos

  • Ambos os turnos (Manhã e Tarde) devem estar FECHADOS.
  • Verifique se não há mesas abertas (todas devem estar fechadas ou pagas).
  • Verifique se não há dívidas pendentes não autorizadas.

6.2 Passo a Passo

Passo 1: No POS, clique no botão "Fecho do Dia" (visível para Gerente/Admin).

Passo 2: O sistema mostra o modal com:

  • Resumo geral: operador, data, total do dia, nº de vendas
  • Turno da Manhã: operador, vendas, modalidades, produtos vendidos
  • Turno da Tarde: operador, vendas, modalidades, produtos vendidos
  • Vendas por Modalidade (total do dia)
  • Produtos Vendidos (total do dia, agregado)

Passo 3: Clique "Ver Relatório" para ver o preview completo.

Passo 4: Verifique: valores dos turnos, produtos vendidos, modalidades.

Passo 5: Se estiver tudo certo, clique "Confirmar Fecho do Dia".

Passo 6: O fecho é guardado no cash_flow (Supabase) com descrição "Fecho do Dia".

Passo 7: O relatório pode ser impresso automaticamente.

ATENÇÃO: Se houver discrepância, NÃO confirme. Verifique os turnos primeiro. O Fecho do Dia só pode ser feito uma vez por dia.

7. Fecho Automático de Caixa

O sistema tem um fecho automático de segurança que funciona mesmo que se esqueça de fazer o fecho manual.

7.1 Como Funciona

Janela de fecho: Entre 04:55 e 04:59 (hora de Luanda), o sistema verifica automaticamente se o dia que está a acabar tem fecho.

Condição: Se não houver fecho registado para a data, o sistema cria automaticamente um fecho com:

  • Soma de todas as vendas do dia (status "closed" ou "paid")
  • Descrição: "Fecho Automático de Segurança — X vendas"
  • Operador: "Sistema (Auto-Fecho)"

Onde funciona: Em qualquer página da app que esteja aberta — POS, Dashboard, Owner Dashboard. Se a app estiver aberta em qualquer página, o fecho automático executa.

7.2 Fecho Retroativo

Se ninguém teve a app aberta às 04:55, o sistema também faz fecho retroativo:

Quando o Owner Dashboard ou Dashboard abre depois das 05:00 e o dia anterior não tem fecho, o sistema cria automaticamente o fecho retroativo com as vendas do dia.

Isto garante que o card "Fecho do Dia" no Owner Dashboard sempre tem um valor.

DICA: Mesmo com o fecho automático, faça sempre o fecho manual no final do dia para conferir os valores. O fecho automático é uma rede de segurança, não substitui o procedimento normal.

8. Controlo de Vendas

O Controlo de Vendas mostra uma análise detalhada de cada produto vendido.

8.1 O que Mostra

  • Vendas por produto: Quantidade vendida, receita gerada, margem de lucro
  • Comparação de períodos: Hoje vs Ontem, Esta Semana vs Semana Passada
  • Ranking de produtos: Os mais vendidos e os menos vendidos
  • Análise por categoria: Entradas, Pratos, Bebidas, Sobremesas
  • Ticket médio: Valor médio gasto por cliente

8.2 Como Usar

Passo 1: Aceda a "VENDAS" na barra lateral.

Passo 2: Selecione o período (Hoje, Semana, Mês, Personalizado).

Passo 3: Veja os gráficos e tabelas de análise.

Passo 4: Use os filtros para ver por categoria ou produto específico.

Passo 5: Exporte em PDF ou Excel se necessário.

9. Menu Público Digital (QR Code)

O Menu Público Digital permite que os clientes vejam o menu nos seus telemóveis através de um QR Code.

9.1 Como Aceder

URL directo: https://rest-ia.vercel.app/menu

QR Code: O sistema gera automaticamente um QR Code que pode imprimir e colocar nas mesas.

Os clientes abrem a câmara do telemóvel, apontam para o QR Code, e o menu abre no browser — sem instalar nada.

9.2 O que o Cliente Vê

  • Categorias do menu (Entradas, Pratos, Bebidas, Sobremesas)
  • Foto de cada produto (se disponível)
  • Nome, descrição e preço em Kwanzas
  • Indicação de disponibilidade (disponível / esgotado)

O menu público atualiza automaticamente quando o administrador altera produtos no Menu & Stock.

9.3 Como Configurar (Admin)

O Menu Público é configurado em Sistema → Configurações. O administrador pode:

  • Activar/desactivar produtos no menu público
  • Definir qual URL usar (pode ser personalizado)
  • Imprimir QR Codes para as mesas

10. Dashboard (Visão Geral para Utilizadores)

O Dashboard mostra um resumo visual do restaurante em tempo real. Mesmo utilizadores sem permissões de admin podem ver alguns cards.

10.1 Cards Principais

  • Faturação Hoje: Vendas do dia em tempo real
  • Despesas Hoje: Gastos do dia
  • Mesas Ocupadas: Quantas mesas estão ativas agora
  • Pedidos Abertos: Contas em curso

10.2 Gráficos

  • Receita Semanal: Vendas dos últimos 7 dias
  • Receita vs Custos vs Break-Even: Comparação semanal
  • Receita por Categoria: Bebidas vs Pratos vs Sobremesas
DICA: Para análises mais detalhadas (lucro, margem, previsões), consulte o Manual do Administrador.

11. Problemas Comuns e Soluções

11.1 O POS não abre / ecrã branco

Solução: Feche a app completamente e abra novamente. Se persistir, verifique a ligação à internet. A app funciona offline, mas precisa de carregar dados do Supabase na primeira vez.

11.2 Vendas não aparecem no Dashboard

Solução: Verifique se a venda tem status "closed" ou "paid". Vendas com status "open" não contam. Se fez venda offline, pode estar pendente de sincronização. Verifique a ligação à internet.

11.3 Impressora não imprime

Solução: Verifique se a impressora está ligada e configurada em Sistema → Configurações → Impressora. Teste a impressão. Se não funcionar, reinicie a impressora e volte a testar.

11.4 Não consigo fazer Fecho do Dia

Solução: Verifique se ambos os turnos estão fechados. Se houver mesas abertas, feche-as primeiro. Se o sistema diz "Já existe fecho", o fecho automático pode já ter executado.

11.5 Esqueci-me do PIN

Solução: Contacte o administrador. Ele pode redefinir o PIN em Sistema → Gestão de Utilizadores.

11.6 A app diz "Offline" mas tenho internet

Solução: O indicador pode demorar alguns segundos a atualizar. Faça refresh (F5). Se persistir, verifique se o Supabase está acessível em Sistema → Diagnosticar.

12. Perguntas Frequentes

P: Posso usar o POS sem internet?
R: Sim! A app funciona offline. As vendas são guardadas localmente e sincronizam automaticamente quando a internet voltar.

P: Quantos utilizadores posso ter?
R: Não há limite. Pode criar quantos utilizadores precisar, cada um com PIN e permissões próprias.

P: O que acontece se o computador falhar?
R: Todos os dados estão guardados no Supabase (nuvem). Faça login noutro computador com as mesmas credenciais e todos os dados restauram.

P: Posso editar uma venda depois de fechada?
R: Não. Vendas fechadas são definitivas para fins fiscais. Se houver erro, faça uma nova venda com valor negativo (desconto) ou contacte o administrador.

P: O fecho automático substitui o fecho manual?
R: Não. O fecho automático é uma rede de segurança. Deve sempre fazer o fecho manual para conferir os valores e gerar o relatório completo.

P: Como adiciono um novo produto ao menu?
R: Apenas administradores podem adicionar produtos. Vá a Menu & Stock → Adicionar Produto. Consulte o Manual do Administrador para detalhes.

P: Posso ver o menu no meu telemóvel?
R: Sim! Aceda a https://rest-ia.vercel.app/menu ou aponte a câmara para o QR Code na mesa.
